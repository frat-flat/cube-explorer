## 1. 現在の実装構造

- 画面: アプリ本体は [public/sheets/axes.html](../../public/sheets/axes.html) の1ファイル(素の JavaScript、約 2,400 行・関数約 340 個、three.js r128)。`/` を開くとこれが出る(`next.config.ts` の rewrite)。③ の調査対象のうち components・hooks・stores・services・types・schema は、アプリ本体には存在しない。
- サーバー: ログイン(Neon Auth)、スプシの読み取り(`/api/sheets/read`、閲覧のみ・1タブ 300 行 × 26 列まで)、保存(`/api/workspace`)の3つ。
- データの持ち方: 画面の中の1つの状態 `S` にすべてを入れる。

| 中身 | 今の形 |
|---|---|
| `axes` | Column Registry のカラム(分類 key / 数値 measure、グループ、サブタイトル、型、状態) |
| `dict`・`links` | 呼び名(＝ ≒ ⊃ ⊂)と、カラム同士の関係(Equivalent・Related・参照) |
| `boxes` | Box と Cube が同じ一覧。親子、自分の値(`own`)、元の行の中身(`info`)、Cube は3軸 |
| `sheets` | 取り込んだ表のコピー(書式つきの文字のまま)と、列ごとの軸の対応。どれか1つの Cube に属する |
| `cards` | 行から作った独立した札(項目と値のコピー) |
| `saved` | Remix で保存した条件(絞り・行・列) |
| `saving` | 反映待ちの表(元の表まるごと＋反映済みの列と行) |
| `history` | 履歴(元・結果・文章) |
| `defs` | Library の種類(自動で分類) |

- 計算: [`facts()`](../../public/sheets/axes.html#L787) が Sheet の数字のセルを「軸の値の組 → 数値＋元のセル」に変える。Remix の表([`runQuery`](../../public/sheets/axes.html#L802))と Cube の面([`faceData`](../../public/sheets/axes.html#L2021))が、それぞれ別に SUM で集計する。
- 保存: ブラウザ(localStorage)と Supabase の `cube_workspaces`(1人1件の JSON、上限 5MB)。開くと Supabase の中身でブラウザ側を上書きする。
- テスト: 単体 24 件(サーバーの部品だけ)、画面 17 シナリオ(Playwright)。

## 2. 新仕様との一致点

- `facts()` の形(軸の値の組・数値・元のセル)は ② の Value モデルの芯に近い。
- Column Registry・呼び名・Equivalent/Related は ② の ColumnDefinition と Semantic Relation、① 30章に合う。
- Box の親子と単位名は ② の Box モデル(親・unit_type)に近い。
- Saving → 人の承認 → 反映直前に元を読み直す、は ① 30章に合う。
- Remix の保存条件(絞り・行・列・縦横入れ替え)は SheetDefinition の原型。
- 集計表のセルから元のセルが見え、合計のセルは直せない。Cell Inspector の原型。
- 履歴が元と結果を持つ。本番に見本データを入れない・初期設定を勝手に決めない・元のスプシを書き換えない(閲覧のみ)も守られている。

## 3. 新仕様との相違点

| 項目 | 今 | 新仕様 |
|---|---|---|
| 保存 | 1人1件の JSON | 意味ごとに分けた表(Canonical Data Model) |
| Sheet | 元の表のコピーをアプリ内で直せる([L1369](../../public/sheets/axes.html#L1369)・[L1785](../../public/sheets/axes.html#L1785))。スプシは変わらず、元とずれる。直したことは履歴に残らない | Source は1つ。Projected Sheet は定義だけ |
| 分ける・まとめる | 行をコピーして新しい Sheet を作る([L1796](../../public/sheets/axes.html#L1796)) | コピー禁止。参照と投影 |
| Box・Card | 元の行の中身をコピーして持つ([L1234](../../public/sheets/axes.html#L1234)) | Box はコピーしない。Card は Box の属性 |
| Cube | 入れ物。Sheet は1つの Cube に属し、3軸は設定で固定 | 定義(投影)。XYZT を入れ替え、T あり |
| 合計 | 合計の行・列を見分ける処理がない。普通の値として入り二重に数える | 合計は Aggregation として別に持つ |
| 集計 | SUM だけ、2か所で別々に計算 | SUM・COUNT・AVG・MIN・MAX を共通の仕組みで |
| 計算・由来 | 元のセルだけ。関数は列ごとに最初の1セルの例だけ | Raw と Calculated を分け、LineageEdge でたどる |
| Selection・Drill | セル1つだけ。Drill・値つきパンくずなし | 範囲を選んで Drill、親の値を保つ |
| 計算の場所 | 全データをブラウザで | サーバー側で絞り・集計してから渡す |

- Sheet: Source Sheet(取り込んだ元)と Projected Sheet(定義)に分ける
- Remix の保存条件 → SheetDefinition(合計・小計のルールを足す)
- `facts`・`runQuery`・`faceData` → 共通の Projection Engine
- Cube → CubeDefinition(軸の設定・Role)
- Card → Box の属性 / Box の `info` → 元の行への参照
- Library の種類分け(3軸の組み合わせでの分類をやめる)
- 分ける・まとめる → コピーせず投影で
- 決め打ちの軸名 `item`・`month`([L1291](../../public/sheets/axes.html#L1291)・[L1399](../../public/sheets/axes.html#L1399)・[L1788](../../public/sheets/axes.html#L1788))をなくす
